# Archived skills

Retired from the active plugin and preserved unchanged; these skills have not been refreshed for v4. Use the [current API docs](https://docs.dev.runwayml.com/) when following older examples.

Install the self-contained `use-runway-api` skill explicitly:

```sh
npx skills add https://github.com/runwayml/skills/tree/main/legacy --skill use-runway-api
```

For `rw-generate-*`, clone this repository and run from `legacy/` so the shared Python helpers resolve. Standalone skill installs omit those helpers. Active Dev skills live in the root `skills/` directory.
