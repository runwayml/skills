# Runway skills catalog audit (August 2026)

Baseline: `runwayml/skills` @ `origin/main` (17 skills, plugin v2.1.0).

## Verdict

**Reuse this repo** as the canonical Runway developer-platform skills package. Do not create a separate `dev-skills` repo — it would fragment discovery (`skills.sh` installs, Claude official listing) without fixing stale sibling content.

The catalog is **not safe to promote as-is**. Repair packaging and stale guidance before adding new Dev Platform skills or wiring quickstart install flows.

## Target architecture (DEV-112)

```
runway-dev                 foundation: MCP connect, llms.txt, project pick, submit/poll, errors
runway-dev-models          model generation integration
runway-dev-model-routers   router propose → approve → MCP create → SDK call
runway-dev-characters      preset/session workflow; avatars terminology
runway-dev-recipes         recipe SDK call pattern
runway-dev-workflows       thin wrapper → MCP get_workflows_setup_guide
```

**Boundary:** MCP tool schemas + `llms.txt` = live contracts. Skills = orchestration, security, approval gates, terminology — not model catalogs or API field lists.

## Quickstart replacement (DEV-296, api repo)

Replace long prompt dumps with:

1. `npx skills add runwayml/skills --skill runway-dev --skill runway-dev-{surface} …`
2. Goal + pinned context (model id, router slug, character UUID, recipe id)
3. Pointer to `llms.txt`

MCP OAuth install strings stay in quickstart when Dev MCP flag enabled; durable workflow moves to `runway-dev`.
